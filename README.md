# SV20 — симулятор управления гоночной яхтой

Проект восстанавливает геометрию яхты SV20 / «610» и рассчитывает её движение,
паруса, ветер и воду в браузере. Цель для пользователя — освоить управление
парусами: видеть последствия настройки, замечать ошибки и восстанавливать ход.

Есть ручное управление рулём, гротом, стакселем, генакером и посадкой экипажа;
авторулевой, речная акватория, волны и средства разбора состояния. Обучающие
упражнения пока не реализованы. Поведение генакера при складывании и устойчивое
глиссирование остаются открытыми задачами. Часть характеристик конкретной SV20
опирается на предположения, а не на измерения.

## Быстрый запуск

Нужны Python 3, Node.js и браузер с WebGPU. Для подгонки корпуса и части
проверок нужны библиотеки в `.venv`; подготовка описана в руководстве разработки.
На чистом checkout сначала получите параметры корпуса:

```sh
python3 -m venv .venv
.venv/bin/pip install numpy scipy pillow
make fit
```

Если `out/params.json` уже существует, достаточно `make`. Для обычной работы:

```sh
make sim
python3 scripts/serve.py --port 8020 --no-open
```

Открывайте [симулятор](http://127.0.0.1:8020/sim/index.html): основной вход
автоматически запускает совместное движение генакера и яхты. На панели
доступны ветер, руль, отпускание/подтягивание верёвки, пауза и перезапуск.
Вне панели `←/→` задают руль, `↑/↓` — работу верёвки, пробел — паузу.
Пока модель работает с замедленным временем на спокойной воде без экипажа.

Основному экрану нужен `out/export/live-sail-default.json`: его создаёт
подготовщик чистой постановки с `--set-default`. После изменения исходников
пересоберите сцену и подготовьте новый вход по [руководству](docs/guides/simulation.md#основной-вход-с-генакером).
Сервер сам страницу не пересобирает.

[Прежний игровой экран](http://127.0.0.1:8020/sim/index.html?legacy=1&ui=game)
и [исследовательская панель](http://127.0.0.1:8020/sim/index.html?legacy=1&ui=debug)
сохраняют основные паруса, экипаж и прежние органы управления.
Это отдельный расчёт; он не продвигается одновременно с общим генакером.
В прежней панели местное давление генакера остаётся опытным режимом,
для базового расчёта снимайте соответствующую галочку.

Акватория собирается отдельно и требует сети:

```sh
make terrain terrain-pack terrain-glb
make sim
```

Без пакета акватории симулятор работает на бесконечной воде. Телефон,
HTTPS, запись состояния и контрольные прогоны описаны в
[руководстве симуляции](docs/guides/simulation.md).

## Устройство репозитория

| Каталог | Назначение |
|---|---|
| `src/sv20/` | Геометрия, гидростатика, подготовка физических данных |
| `scripts/` | Сборка, сервер, воспроизведение и измерения |
| `sim/` | Модель движения, ткань, сцена и управление |
| `tests/` | Проверки модели и исследовательские эксперименты |
| `cfd/` | Подробные расчёты воздуха и воды вне интерактивного симулятора |
| `data/` | Чертёж, измеренные таблицы, источники и разметка |
| `assets/`, `viewer/` | Ассеты, просмотрщики и поставляемые зависимости |
| `docs/` | Цели, подсистемы, рабочие инструкции, развитие и доказательства |
| `out/` | Производные пакеты, записи и результаты; не коммитится |
