# Правила подготовки геометрии

Тяжёлых производных файлов здесь нет и не будет: они лежат в `out/cfd/geometry/`
и в git не идут. Здесь — только правила, по которым они получаются.

## Откуда берётся

Источник один — `out/export/*.stl` от `scripts/export.py`. Он же выгружает
`sv20.json` с геометрическими свойствами. Ничего не рисуется заново: любая
вторая копия обводов рано или поздно разойдётся с первой.

## Что делает `cfd-geometry`

1. читает тела выгрузки и запоминает отпечаток каждого входного файла;
2. переводит их в связанные оси CFD (`cfd/lib/axes.py`, один переход на всё);
3. ставит тело в положение случая — крен поворачивает ТЕЛО, дрейф поворачивает
   ПОТОК (иначе плоскость невозмущённой воды перестаёт совпадать с `z = 0`);
4. проверяет замкнутость КАЖДОГО тела после перевода;
5. собирает союзы тел в один многосоставный STL с именованными solid'ами;
6. проверяет связность союза по габаритам;
7. строит канонические тела этапа 0 (`--canonical`);
8. пишет `geometry.json` с отпечатками и отчётом.

## Про союзы

`underwater` — корпус, колодец, перо киля и бульб. Между ними нет воды, и щель
в стыке сеточник примет за щель настоящую.

Руля ни в одном союзе нет: он не касается ни киля, ни корпуса и поворачивается
отдельно. Проверка связности это подтверждает, а не предполагает.

Настоящая булева операция не делается. `snappyHexMesh` умеет работать с
несколькими пересекающимися поверхностями напрямую, а надёжный CSG ради одного
стыка — недели работы. Именованные solid'ы нужны затем, чтобы силы снимались по
телам раздельно: сумма отвечает на вопрос «сходится ли», силы по телам — на
вопрос «что именно разошлось».

## Чего ещё нет

Поверхностей парусов. Форма сечений живёт в `sim/membrane.js`, и её выгрузка в
STL — следующая работа (см. «что осталось» в `cfd/README.md`). До неё случаи
`sail-2d` и `rig-3d` проходят проверку манифеста, но не разворачиваются.

## Единицы

Метры. Всегда. STL не хранит ни единиц, ни имён осей, поэтому рядом с ним
обязателен `geometry.json` — без него метры от миллиметров отличает только
чутьё, а ошибка в тысячу раз выглядит как ошибка модели турбулентности.
