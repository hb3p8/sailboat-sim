# Принятые эталонные таблицы

Сюда кладутся компактные CSV/JSON с силами, коэффициентами и оценкой
погрешности — то, что уже прошло проверки и принято как эталон. Гигабайты
полей остаются в `out/cfd/runs/` и во внешнем хранилище; восстанавливаются они
по `case_id` и отпечаткам из сводки.

Что не принимается:

- запуск, у которого `clean: false` — каталог решателя правили руками;
- запуск с грязным рабочим деревом git — по нему нельзя восстановить исходники;
- одиночная сетка без тройки: погрешность для неё неизвестна, а число без
  погрешности эталоном не бывает;
- сила, дрейфующая на окне усреднения: сравнивать её просто не с чем (§4.3).

Таблицы версионируются. Изменение геометрии, образа решателя, сеточного
шаблона или физической постановки создаёт НОВУЮ версию, а не переписывает
старую молча (§6).
