# Принятые эталонные таблицы

Здесь хранятся компактные CSV/JSON с силами, коэффициентами, происхождением
и оценкой неопределённости. Сетки и поля остаются в `out/cfd/runs/` или внешнем
хранилище; связь с ними восстанавливается по `case_id` и отпечаткам.

Приёмка следует [требованиям CFD](../../docs/subsystems/offline-cfd.md).
Не принимаются изменённые вручную каталоги (`clean: false`), результаты
с невосстановимыми исходниками, одиночная сетка без оценки сходимости и
усреднение по окну с необъяснённым дрейфом сил. Численный эталон и измерение
настоящей яхты имеют разное происхождение и не подменяют друг друга.

Новая геометрия, решатель, сетка или физическая постановка получает новую
версию. Старые таблицы и связанные манифесты не перезаписываются.
