# Собранные отчёты

`make cfd-report FAMILY=...` пишет сюда Markdown: таблицы сеточной сходимости и
сравнение с realtime-моделью.

Отчёт хранит САМИ РАЗНОСТИ, а не только вердикт. Пороги §4.2 — начальные
инженерные, и §4.2 прямо требует оставить возможность пересмотреть их, не
перезапуская расчёты.

Статус `ok` / `investigate` / `model-change` ставится правилом из
`cfd/lib/report.py`, а не оценкой цвета графика. `model-change` означает только
то, что выполнены два условия §4.5 из пяти: расхождение больше объединённой
неопределённости и повторяется в нескольких соседних режимах одним знаком.
Остальные три — влияние на ход лодки и натурная валидация — за человеком.
