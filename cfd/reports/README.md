# Отчёты сравнения

`make cfd-report FAMILY=...` пишет Markdown с сеточной сходимостью и
сравнением с интерактивной моделью. Отчёт сохраняет исходные разности и
неопределённости, чтобы критерии можно было пересмотреть без повторного расчёта.

Статусы `ok`, `investigate`, `model-change` определяет `cfd/lib/report.py`.
`model-change` отмечает превышение объединённой неопределённости и повторение
расхождения в соседних режимах. Влияние на движение лодки, сопоставимость
постановок и натурная проверка оцениваются отдельно по
[правилам приёмки](../../docs/subsystems/offline-cfd.md).
Статус является основанием рассмотреть изменение, а не автоматически принять его.
