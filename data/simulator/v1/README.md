# Проверенные входы симулятора, версия 1

Обычный `make sim` использует [манифест](manifest.json): пакет физики и сетки
лодки, два кроя генакера и два вычислительных WASM-модуля. Все файлы входят
в Git; сборщик проверяет SHA до записи страницы. Пакет весит около 0.74 МБ.
Для обычного запуска не нужны `out/`, `tests/`, `.venv` или компилятор LLVM.

Файлы скопированы побайтово из принятого входа обычной ветки на `a8e9656`,
без пересчёта геометрии, таблиц сил или ткани. Источник и SHA указаны в
`provenance` манифеста. Архивные пути внутри JSON кроя описывают происхождение;
исполняющий код читает рабочие адреса физики и WASM из манифеста.
Эти данные не являются новой приёмкой G1–G4/C1.

Не исправляйте числа или контрольные суммы вручную ради успешной загрузки.
Для изменения данных подготовьте новую версию каталога из отдельных принятых
артефактов, сохраните их происхождение и SHA, сверьте геометрию/массы/силы,
ткань, лодку и оба направления ветра, затем явно переключите сборку и вход.
`make physics` и исследовательский `--set-default` эту версию не обновляют.
