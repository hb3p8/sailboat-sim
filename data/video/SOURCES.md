# Видеоисточники для реконструкции берега

Съёмка берётся для восстановления облика береговой линии (план Б: карта из
открытых данных даёт верную геометрию, но берег по ней не узнаётся). Результат
— геометрия берега, расставленная по карте акватории.

Сами видеофайлы и всё, что из них насчитано, **не коммитятся** — каталог
`data/video/` в `.gitignore`. Здесь только откуда что взято.

Проект личный, некоммерческий, никуда не публикуется. Ролики — чужая работа под
обычной лицензией YouTube, то есть производные от них материалы распространять
нельзя. Если проект когда-нибудь станет публичным, эти реконструкции придётся
либо выкинуть, либо заменить собственной съёмкой, либо спрашивать разрешение у
авторов. Записано здесь, чтобы этот вопрос не всплыл неожиданно.
