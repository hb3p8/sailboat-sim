# Документация SV20

Документация описывает работающую систему, её ограничения и проверяемый путь
к обучению управлению парусами. Текущее состояние хранится отдельно от результатов
конкретных экспериментов. Дата проверки и границы вывода обязательны для чисел.

## Цели и состояние

- [Глобальные цели](project/goals.md) — польза для учащегося и критерии готовности.
- [Текущее состояние](project/status.md) — реализованное, опытное и открытые блокеры.
