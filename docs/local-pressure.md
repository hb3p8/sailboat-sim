# Локальное давление генакера вне общей решётки

25 сентября 2026. Статус: **эксперимент, NO-GO для штатного включения**.
Реализация: `sim/local-pressure.js`, подключение: `Cloth.advance()`.

## Постановка и граница утверждения

Проверяется гипотеза: заданной полярой нормальной силы и текущей формы строки
достаточно, чтобы приближённо восстановить локальную раскладку давления
двумерным тонким вихревым листом. Это собственное замыкание проекта,
не опубликованная модель отрывного обтекания генакера. Вне общей решётки
оно вновь вводит **локальное потенциальное приближение**, с явно заданной
равнодействующей. Проверка пластины подтверждает математику решателя,
но не подтверждает эту гипотезу для сорванного паруса.

В каждой строке строится плоскость хорды и штатной нормали нагрузки ткани.
Форма берётся из имеющихся узлов, с линейной интерполяцией между ними.
Косинусное размещение 16/32/64 аэродинамических панелей уточняет решение
на этой форме; новой геометрической информации между девятью узлами ткани
оно не добавляет. Касательная скорость — проекция местного потока полоски,
с его затенённой величиной `ve`.

На каждой панели вихрь помещён в 1/4, условие непротекания — в 3/4:

```
Σ Kij Γj + λ nz,i = −U·ni
Δpi = −ρ Ut,i Γi / Δsi
Σ Δpi Δsi b nz,i = Fn
```

`Γi` положительна против часовой стрелки, `n=(-tz,tx)`, `+z` направлена
по нормали строки. `λ` — дополнительная неизвестная, равномерная поправка
нормального потока. Последнее уравнение замыкает систему заданной силой
`Fn` из прежнего пути нагрузки ткани. Касательная скорость в линейном
Бернулли фиксируется по входному потоку; поправка λ туда не подставляется.
Система обезразмерена по хорде и скорости. Нулевой интеграл силы допустим:
встречные местные нагрузки сохраняются, деления на их сумму нет.

Форма нагрузки зависит от геометрии, а её интеграл задан полярой. Давление
консервативно переносится в материальной координате на два соседних узла:
сохраняются сумма и первый момент по этой координате. На используемой здесь
кусочно-линейной геометрии и при одинаковой нормали строки это сохраняет также
все три компонента силы и все три компонента пространственного момента
**при переносе панель → узлы**; независимая численная проверка приведена ниже.
Это ещё не доказывает передачу изменившегося момента лодке.
Направление силы пока остаётся штатной нормалью строки. Ткань меняет форму,
и следующий вызов аэродинамики получает эту форму. Общая пелена продолжает
получать только прежнюю циркуляцию поляры — локальные вихри в неё не добавляются.
Существующее демпфирование движения ткани `ρ V vn` сохранено; в новом решателе
скорость деформации повторно не учитывается. Новая часть квазистационарна:
истории вихрей и члена нестационарного Бернулли в ней нет.

## Явные ограничения

- Модель не предсказывает начало отрыва, размер зоны рециркуляции и сход LEV.
  У Ramesh et al. (2014) к тонкому профилю добавлены отдельный сход вихрей
  с передней кромки и критический LESP, зависящий от профиля и Reynolds:
  [аннотация первичной статьи](https://eprints.gla.ac.uk/99370/).
  Таких данных для нашего генакера здесь нет; критический параметр не назначен.
- При обратном потоке по хорде (`Ux≤0`) используется прежняя раскладка с
  причиной `reverse-flow`. Условие на задней кромке нельзя переносить на
  другой конец молча. В опыте 150°/8.5 м это одна из 11 строк всё окно.
- Вырожденная геометрия, сингулярность и относительная невязка выше `1e-8`
  возвращают явный отказ; давление не обрезается под допустимый результат.
- Для активных полосок общей решётки действует прежняя нагрузка. Вне неё
  модель включается только явным `b.o.localPressure = true` (16 панелей)
  или `b.o.localPressure = {panels: 32}`. Штатное значение — выключено.
- Суммарная сила и момент лодки пока приходят из полосочной аэродинамики,
  включая прежние точки приложения. Локальная раскладка действует на ткань;
  перенос изменившегося центра давления в моменты лодки ещё не реализован.
  Это самостоятельный блокер признания полной физической связи законченной.
- `g.q` сохраняет смысл циркуляции общей вихревой системы. Локальное давление
  хранится отдельно и не подменяет это поле. Прежняя `luffFrac` по-прежнему
  не является измеренной долей локального отрыва; заворот в опытах меряется
  непосредственно по геометрии ткани.

`cloth.pressureForce` содержит действительно приложенные скалярные силы
последнего подшага. `cloth.localPressureProfiles` содержит давление каждой
локальной панели, её материальную координату, интегральную силу, λ,
невязку и причины отказов. Аудит читает буфер приложенной силы; прежний
аудит реконструировал её из `q` следующего шага и коэффициентов предыдущего.

## Независимые проверки решателя

`node tests/local-pressure.test.mjs` проверяет пластину по аналитическому
распределению `sqrt((1−x)/x)`. Точное положение центра нагрузки — 0.25 хорды,
доля силы в первых 10 % — 0.395819. Получено:

| Панелей | Центр нагрузки / хорда | Доля силы в первых 10 % |
|---:|---:|---:|
| 8 | 0.282718 | 0.330113 |
| 16 | 0.266095 | 0.366365 |
| 32 | 0.257945 | 0.381136 |
| 64 | 0.253941 | 0.388810 |

Допуски заданы шагом панели `1/N`, ошибка центра должна уменьшаться.
Проверяются также отражение геометрии/потока/силы, квадратичное масштабирование
по скорости, подобие при изменении размера, изменение профиля при изменении
кривизны и ненулевые встречные нагрузки при нулевой равнодействующей.
Сумма и первый момент переноса на 9/17/33 узла проверяются с допуском `1e-10`.

`node tests/local-pressure-coupling.test.mjs` замораживает вход одного
подшага ткани: на обоих галсах сумма сил **каждой строки** сохраняется до
`1e-8` относительно её масштаба, при изменившемся распределении. При включённой
общей решётке силы и положения узлов совпадают точно с контролем.
Эти проверки необходимы для численной корректности, но не являются сравнением
с экспериментальным давлением генакера.

`node tests/local-pressure-frozen.mjs` после 30 с динамики замораживает шесть
разных летящих форм при 140°/6 м/с. Для каждой сохраняются геометрия, поток
и прежняя суммарная сила строки; меняется только 16/32/64/128 локальных панелей.
Во всех 24 решениях перенос панель → узлы сохраняет каждую из шести компонент
трёхмерной силы и момента с относительным допуском `1e-9`.

| Источник летящей формы, шкот | Угол входа строки | Доля силы первых 10 % хорды, 16 → 128 панелей | L1 узлов против 128, 16 → 64 панели | Центр силы / хорда при 128 |
|---|---:|---:|---:|---:|
| штатная, 9.0 м | +23.5° | −4.5 → −5.8 % | 6.86 → 0.99 % | +0.596 |
| локальные 16, 9.0 м | −12.0° | 102 → 116 % | 13.66 → 2.04 % | −0.774 |
| локальные 32, 9.0 м | −3.5° | 122 → 136 % | 12.51 → 1.79 % | −0.779 |
| локальные 64, 9.0 м | +3.7° | 169 → 186 % | 11.71 → 1.60 % | −1.134 |
| локальные 32, другой галс, 9.0 м | +20.7° | 240 → 260 % | 12.61 → 1.61 % | −1.465 |
| локальные 32, 8.5 м | +23.8° | −1.9 → −2.9 % | 6.30 → 0.90 % | +0.566 |

Значение доли выше 100 % означает встречную нагрузку за первыми 10 % хорды;
центр за пределами хорды — следствие компенсации нагрузок разных знаков.
При **одной** форме профиль по числу панелей сходится, но связанные расчёты
приводят ткань к **разным** формам и даже разным знакам угла входа. Увеличение
числа аэродинамических панелей само по себе эту связанную неоднозначность не
устраняет. Возможность таких больших встречных нагрузок физически не
подтверждена независимым измерением давления для соответствующей формы.

Относительно прежнего ровного давления на той же форме изменение момента
лишь одной наиболее подозрительной строки при 128 панелях составляет
`ΔMx=−69…−81 Н·м`, `ΔMz=+165…+174 Н·м` на положительном галсе при 9.0 м;
на другом галсе `+82/−156 Н·м`. Это диагностические моменты строки, **не**
поправка к моменту лодки. `Rig.forces()` продолжает вычислять её моменты из
полосочных сил и прежних точек приложения. Подключать этот сдвиг без
согласования полной силы ткани с полосочной силой и проверки физического
профиля нельзя.

## Сгущение самой ткани: отрицательная проверка

`node tests/local-pressure-cloth-resolution.mjs` оставляет те же 11 строк,
`30 Гц`, 40 проходов проектора и 32 локальные панели, но меняет число
материальных столбцов `9/17/33`. TWA 140°, TWS 6 м/с, шкот 9.0 м, старт
3 м/с; средняя тяга и минимум угла входа — из окна 25…30 с. Контроль
`--baseline` полностью выключает новый локальный профиль. Угол — минимум
по внутренним строкам и времени окна, а складка (`back/flip`) — на самой
подозрительной строке в конечном снимке.

| Давление / галс | Столбцы | Тяга, Н | Мин. вход, ° | Ход назад / вывернуто, % | Макс. скачок тяги, % |
|---|---:|---:|---:|---:|---:|
| штатное / + | 9 | 396.9 | +23.6 | 0 / 0 | 0.1 |
| штатное / + | 17 | 371.0 | −23.9 | 3.5 / 25.0 | 1.5 |
| штатное / + | 33 | 390.0 | −14.1 | 7.5 / 37.4 | 21.7 |
| штатное / − | 9 | 409.0 | +23.4 | 0 / 0 | 0.0 |
| штатное / − | 17 | 373.1 | −25.6 | 2.1 / 31.3 | 11.3 |
| штатное / − | 33 | 406.0 | −11.0 | 7.5 / 34.3 | 14.1 |
| локальное / + | 9 | 394.7 | +11.0 | 0 / 0 | 0.0 |
| локальное / + | 17 | 392.5 | +26.2 | 0 / 0 | 3.2 |
| локальное / + | 33 | 395.3 | +46.4 | 0 / 0 | 11.7 |
| локальное / − | 9 | 370.8 | +12.2 | 0 / 0 | 0.0 |
| локальное / − | 17 | 475.9 | −23.5 | 0 / 0 на конечной строке | 10.0 |
| локальное / − | 33 | 391.8 | +38.1 | 0 / 0 | 12.0 |

Это не сходимость ткани, причём **уже при штатном давлении**: сгущение
даёт складку и меняет знак входа на обоих галсах. При 8.5 м и штатном
давлении на положительном галсе результат тот же: минимальный вход
`+23.6/−21.5/−15.6°`, вывернутость `0/37.3/40.5 %`, скачок
`0.0/0.1/17.8 %` для 9/17/33 столбцов. Следовательно, это не исключительно
явление на наиболее отпущенном шкоте и не ошибка только нового профиля.

Увеличение числа проходов не снимает неоднозначность локального опыта при
9.0 м: у 17 столбцов минимум входа `+26.2/−23.9/−13.0°` при
40/80/160 проходах; у 33 столбцов `+46.4/+32.9/+28.8°`, а скачок общей
тяги `11.7/13.4/1.6 %`. При 160 проходах строка с 17 столбцами имеет
`back=56.5 %`, `flip=24.9 %`, то есть нерасправленную ткань нельзя принять
за удачный заворот. Прежний предел скачка **5 %** не менялся.

У 33 столбцов худшее удлинение строки `4.25 %` приходится на жёсткую
верхнюю дощечку: её длина в пространстве `0.261 м` против `0.250 м` в
крое, и число не уменьшается даже при 160 проходах. На остальных строках
удлинение не больше `0.26 %` в приведённых опытах. Поэтому 4.25 % нельзя
называть растяжением середины полотна; однако знак входа, складки и скачок
силы остаются самостоятельными отрицательными свидетельствами.

Причина артефакта дощечки измерена отдельно: её узлы раскладывались по
плоской координате `px`, делённой на ширину **трёхмерного** кроя. На 33
столбцах предпоследний узел имеет параметр `t=1.021`, уже за задним
концом, а последний возвращается на конец. Явный вариант
`--board-material` кладёт узлы по доле кроя `c/(N−1)`. При штатном
давлении, положительном галсе и 9.0 м он уменьшил ошибку верхней строки
`4.25 → 0.29 %`, но оставил вывернутость `34.2 %` и **увеличил**
максимальный скачок тяги `21.7 → 41.7 %`; тяга изменилась
`390.0 → 345.7 Н`. Кроме того, полный штатный `gennaker.test.mjs` с
безусловным вариантом получил новую красную клетку: размах тяги `13 %`
на TWA 120°/шкоте 5.5 м/ветре 6 м/с. Поэтому геометрически оправданное
исправление пока оставлено **только явным диагностическим переключателем**,
штатная укладка не изменена. Одна дощечка не решает сеточную несходимость
полотна; регрессию нельзя принимать за положительный результат.
Диагностический стенд подтверждает положение каждого внутреннего узла на
материальном отрезке с абсолютным допуском `1e-9`; после возврата прежнего
штатного пути полный `node tests/gennaker.test.mjs` снова прошёл (худший
размах тяги 6 % по его существующим воротам). Замороженные профили давления
вернулись точно к числам таблицы выше.

Диагностическое отключение жёсткости на излом (`--bend=0`) при 40 проходах,
штатном давлении, положительном галсе и 9.0 м не восстанавливает форму:
на 17/33 столбцах минимальный вход `−17.6/−25.9°`, ход назад
`16.3/11.5 %`, вывернутость `25.4/47.8 %`, залом `95.6/116.3°`.
Следовательно, один только коэффициент излома не объясняет сеточную
несходимость; его подбор вместо устранения причины не обоснован.

`--gate` использует только существующий предел скачка 5 %. Для контрольных
`--baseline --cols=33 --gate` при 9.0 м на положительном галсе получены
21.7 % и код выхода `1` — намеренный машиночитаемый отрицательный свидетель.

Никакого сгущения штатной ткани или настройки жёсткости по этим числам не
сделано. Перед разработкой модели отрыва надо восстановить сходимость формы
ткани на этих режимах (включая конструкцию дощечки), затем повторить парный
манёвр и оба галса. Нынешняя сетка не даёт независимой геометрической опоры
для калибровки давления.

### Замороженный аэродинамический вход: источник ветвления — ткань

`node tests/cloth-frozen-aero-grid.mjs` сперва доводит штатную лодку на
140°/6 м/с/шкоте 9.0 м до 30 с, затем **не шагает лодку и полоски**.
Новые экземпляры ткани 11×9/17/33 получают тот же `stripCalc`, `stripState`,
крен, ветер и шкот в течение ещё 30 с. Стенд проверяет побайтовую
неизменность выбранных входов после каждой сетки. Исходный максимальный
разброс `q` по хорде равен нулю: нагрузка уже равномерна в этих режимах;
повторно «выравнивать q» было бы пустым контролем. Проектор — 40 проходов,
шаг 30 Гц. Крой и первый шаг всех сеток расправлены (`back=flip=0`).

| Галс | Столбцы | Мин. вход после 30 с, ° | Макс. ход назад / вывернуто, % | Пузо строки 5 / хорда, % |
|---|---:|---:|---:|---:|
| + | 9 | +23.6 | 0 / 0 | 26.0 |
| + | 17 | −23.3 | 248.3 / 31.2 | 74.3 |
| + | 33 | −10.7 | 18.1 / 37.4 | 25.9 |
| − | 9 | +23.4 | 0 / 0 | 25.9 |
| − | 17 | −24.9 | 174.9 / 37.5 | 72.7 |
| − | 33 | −11.1 | 17.1 / 43.7 | 22.9 |

Различие развивается после чистого первого шага: уже к 5 с ткань 17/33
столбца на положительном галсе имеет отрицательный угол входа
`−16.6/−23.8°`. Это **не** обратная связь обновляемой аэродинамики:
её входы остаются фиксированными. На 17/33 столбцах и 160 проходах угол
после 30 с остаётся `−17.2/−8.9°`, ход назад `94.3/19.1 %`;
удвоение частоты ткани до 60 Гц при 40 проходах воспроизводит прежние
`−23.3/−10.7°` и ход назад `248.3/18.1 %` практически без изменения.
Значит, одной доводкой итераций или уменьшением шага этот переход не снять.
Точная причина и физическая ветвь ещё не установлены: возможны несколько
равновесий гибкой ткани под следящей нагрузкой либо недостаточная физическая
регуляризация кромок/швов. Называть крупную сетку «истиной» тоже нельзя.

Дополнительное разделение механизма — только диагностическое, не штатная
физика. При `--fixed-normals` направление давления запомнено с первого
расправленного подшага, но его величина и те же полосочные входы остаются.
Через 30 с на положительном галсе у 17/33 столбцов вход всё ещё
`−13.4/−4.0°`, ход назад `232.6/14.5 %`, вывернутость `24.9/9.3 %`.
Следящая нормаль усиливает складку, но не является её единственной причиной.
Увеличение оценочной жёсткости излома `0.05 → 0.4` при прежних 40 проходах
расправляет 17 столбцов лишь после переходных 10…20 с, тогда как 33
столбца остаются с входом `−25.1°` и вывернутостью `18.8 %` на 30 с.
Это чувствительность к регуляризации, **не** калибровка жёсткости ткани:
одно число не дало сеточно-независимого решения и не переносится в игру.

### Когда начинается складка и что происходит со шкаторинами

К тому же стенду добавлен `--edges`: он показывает ранние 0.5…3 с,
строку наибольшего хода назад и отношение длины летящих рёбер каждой
боковой шкаторины к длине по крою. Признак «почти расправлено» означает
`d / d_крой ≥ 0.995` и служит лишь для диагностики геометрии: из него
нельзя получить натяжение или принять физическую модель.

При 140°/6 м/с/шкоте 9 м и том же замороженном входе:

| Галс / столбцы | Через 0.5 с: мин. вход | Через 0.5 с: наибольший ход назад | Шкаторины: длина / крой; почти расправленные рёбра | Через 30 с: мин. вход |
|---|---:|---:|---:|---:|
| + / 9 | контроль штатного разрешения | 0 % | — | +23.6° |
| + / 17 | −24.5° | 116.6 % хорды, строка 9 | 99.9/100.1 %; 10/10 из 10 | −23.3° |
| + / 33 | −9.0° | 241.5 % хорды, строка 7 | 99.9/100.0 %; 9/10 из 10 | −10.7° |
| − / 9 | +24.7° | 0 % | 100.0/99.6 %; 10/7 из 10 | +23.4° |
| − / 17 | −24.6° | 117.6 % хорды, строка 9 | 99.9/100.1 %; 10/10 из 10 | −24.9° |
| − / 33 | −7.5° | 230.2 % хорды, строка 7 | 99.9/100.0 %; 9/10 из 10 | −11.1° |

На положительном галсе к 30 с у 17 столбцов длина передней/задней
шкаторины составляет 99.8/100.0 % кроя, у 33 — 100.0/100.0 %;
на зеркальном — 99.6/100.0 и 100.0/100.0 %. Следовательно, переход
начинается сразу на обеих густых сетках и почти зеркален; его нельзя
объяснить только суммарной слабиной боковых шкаторин. Продольный размер
близок к крою даже при огромном уходе внутренних узлов назад. Это не
доказывает физическое натяжение швов: позиционный решатель не считает
реакции связей. Проверка распределения по ячейкам и физически заданных
граничных связей остаётся открытой; изменять `BEND` или включать местное
давление из этого результата нельзя.

### Полностью постоянная понодальная сила: складка сохраняется

`--fixed-load` сохраняет с первого расправленного подшага нормали строк и
летящие площади узлов. Лодка и полоски по-прежнему не шагают; стенд
проверяет точное постоянство чисел `pressureForce` после каждого шага ткани.
Следовательно, внутри каждого опыта аэродинамическая сила **в каждом узле**
постоянна, хотя затухание по скорости остаётся. На обоих галсах при
140°/6 м/с/шкоте 9 м, 40 проходах и 30 Гц результат всё равно расходится:

| Галс | Столбцы 9 / 17 / 33: мин. вход через 30 с, ° | Ход назад 17 / 33 через 30 с, % хорды | Постоянный суммарный Fx/Fy на всех трёх сетках, Н |
|---|---:|---:|---:|
| + | +23.5 / −13.3 / −3.9 | 232.4 / 14.5 | +179.0 / −203.5 |
| − | +23.5 / −6.6 / −11.1 | 213.0 / 14.9 | +184.7 / +208.3 |

Через 0.5 с вход на 17/33 столбцах уже отрицателен: на положительном
галсе `−25.7/−10.6°`, на зеркальном `−26.2/−9.4°`. Значит,
неустойчивость не вызвана только изменением направления или величины
давления при деформации ткани. Это опыт с *заданной* аэродинамической
силой, а не доказательство корректности её физического распределения.

`--cells` показывает рёбра строки с наибольшим ходом назад. Через 30 с
на положительном галсе у 17 столбцов строка 7 прошла назад 232.4 % хорды,
но её дуга составляет 100.2 % длины кроя; ни одно из 16 рёбер не короче
своей длины по крою более чем на 0.5 %, одно длиннее более чем на 1 %
(min/max 99.8/101.0 %). На 33 столбцах строка 8 прошла назад 14.5 %,
при дуге 100.0 % кроя, 4 слабых и 1 растянутом более чем на 1 % ребре
из 32 (98.1/101.1 %). На другом галсе та же картина: у 17 столбцов
строка 7 имеет дугу 100.2 % и ход назад 213.0 %, у 33 — строка 8
99.7 % и 14.9 %. Суммарной нехваткой длины или локальной слабиной
всех звеньев это не объяснить: решатель допускает иное пространственное
уложение почти нерастяжимой ткани. Натяжений/реакций в существующем PBD
нет, поэтому физический выбор ветви и сеточная сходимость остаются NO-GO.

Проверка `--cut-nesting` сопоставляет трёхмерные координаты проектной
поверхности в **общих узлах** сеток 9, 17 и 33 (все 11 строк). На обоих
галсах максимум разности для пар 9↔17, 9↔33, 17↔33 равен ровно
`0.000e+0 м`; тест теперь останавливается при несовпадении более `1e−9 м`.
Разница угла входа *дискретных* сечений кроя на первом шаге поэтому
объясняется разрешением касательной у передней кромки, а не различием
проектной поверхности в совпадающих точках. Это снимает ещё одну простую
причину складки, но не подтверждает сходимость динамики ткани.

### Скачок шкотового угла при холодном старте: крупная часть причины

Крой строится на середине допустимого шкота: `(1.231 + 9.205)/2 = 5.218 м`.
При независимом старте сразу со шкотом `9.0 м` первый шаг `Cloth.step()`
сначала ставит угол на рабочую дугу, но `seed()` затем перезаписывает его
координатой кроя. На следующем шаге дуга вновь навязывается закреплённому
углу. Измеренное расстояние между этими позициями **4.2734 м** на обеих
сетках и галсах; на положительном галсе координаты в риге
`(3.871, −4.583, 1.764) → (7.804, −5.090, 3.358) м`.
Это не растяжение шкота за один кадр, а скачок граничного условия для
расчётной ткани. Штатная сетка из 9 столбцов его маскирует.
Этот путь достижим и в интерфейсе: `sim/controls.js` каждую рамку напрямую
пишет значение ползунка в `o.genSheetLen`; отдельного состояния фактически
выпущенного шкота или ограничителя скорости нет. В частности, клик по
дальней точке ползунка задаёт новую длину без переходного движения.

В диагностике `--load-scale=0 --gravity-scale=0` внешние силы исключены.
Если оставить скачок, после 30 с у 17/33 столбцов ход назад
`174.8/124.6 %` хорды, а вход `−7.7/−170.0°`; у 9 столбцов складки нет.
Если после первого шага **оставить шкотовый угол в позиции кроя**
(`--hold-cut-clew`), все три сетки остаются расправленными: ход назад и
вывернутость `0/0 %`. Это изоляция причины, но не допустимое управление:
физический шкот 9 м уже не выполняется.

Плавная диагностическая смена шкота от 5.218 до 9 м за 10 с при нулевых
силах сохраняет 17 столбцов расправленными, а у 33 снижает ход назад до
`6.7 %`, вывернутость остаётся `18.8 %`; материальная укладка дощечки
даёт `2.8/21.9 %`, тоже не ноль. Со штатной замороженной нагрузкой при
том же плавном движении **все три** сетки через 30 с расправлены на обоих
галсах, пузо строки 5 `25.9…26.0 %` хорды. Прогоны с переходом за
1 и 5 с на положительном галсе также дают расправленный конечный кадр,
но на 33 столбцах видна временная складка: при 5 с перехода в момент
5 с `back/flip=1.0/12.5 %`, при 1 с в момент 5 с — `5.0/21.9 %`.
Значит, история трима существенна; выбирать 10 с как «исправление» нельзя.

Проверка с **обновляемыми** аэродинамикой и лодкой, штатным давлением,
переходом за 10 с, окном 25…30 с:

| Галс | 9 / 17 / 33 столбца: средняя тяга, Н | 9 / 17 / 33: максимальный скачок тяги от 10 с, % | Форма в конце |
|---|---:|---:|---|
| + | 406.1 / 404.3 / 402.2 | 1.7 / 1.6 / 1.0 | все расправлены |
| − | 412.3 / 409.3 / 404.8 | 3.2 / 2.2 / **8.9** | все расправлены |

На зеркальном галсе 33 столбца по-прежнему нарушают **прежний** предел
скачка `5 %`; максимум при `t=11.50 с`, после 20 с новых скачков нет.
`--gate` на этом варианте возвращает код `1`, не меняя порог.
Диагностическая укладка дощечки по материальной доле убрала её лишнюю
длину `4.25 % → 0.15 %`, но скачок только `8.9 → 8.6 %`.
При переходе за 5 и 1 с у 33 столбцов тот же показатель `4.1` и `3.9 %`:
немонотонная зависимость от истории, а не надёжная настройка времени
травления. Порог не менялся, вариант по времени не выбран для игры.
Локальное давление и realtime-поляра остаются выключенными: нет ни
устойчивого прохождения ворот на обеих сторонах, ни доказанной физической
модели привода шкота и начальной постановки.

### Свободный шкотовый угол без навязанной дуги тоже не проходит

Проверен уже существующий `Cloth.freeClew`: шкот ограничивает только
расстояние до обуха, угол свободен. Это устраняет именно принудительный
скачок на дугу и физически правильнее описывает слабину, но текущая
ткань ещё не даёт сеточной сходимости. При независимом старте на
140°/6 м/с/шкоте 9 м, штатной аэродинамике, 40 проходах, окно 25…30 с:

| Галс | 9 / 17 / 33: средняя тяга, Н | 9 / 17 / 33: скачок тяги, % | Слабина шкота на 30 с | Уход угла с дуги на 30 с, м |
|---|---:|---:|---:|---:|
| + | 338.7 / 319.5 / 257.2 | 4.3 / 4.6 / 4.8 | 0 / 0 / 0 м | 1.266 / 1.596 / 1.431 |
| − | 321.9 / 303.2 / 242.2 | **12.2 / 12.0 / 60.6** | 0 / 0 / 0 м | 1.456 / 1.428 / 1.546 |

На положительном галсе сетка 33 имеет отрицательный минимум входа
`−7.5°`, хотя в строке с этим входом хода назад в конце нет;
на зеркальном максимальный скачок 60.6 % происходит в 25.13 с,
не только в момент постановки. Средняя тяга между 9 и 33 столбцами
различается на 24.1/24.8 % по галсам. На 33 столбцах плавная смена
шкота за 10 с на положительном галсе дала тот же конечный результат,
что и независимый старт (257.2 Н, `−7.5°`, 4.8 %): одной историей
движения здесь несходимость не снять. Критерий 5 % не ослаблен.
Включать свободный угол только потому, что он устраняет искусственную
дугу, нельзя: надо обеспечить физически определённое натяжение
шкаторин и проверяемую сеточно-независимую форму.

Доводка числа проходов на **той же** сетке 11×33 не устранила отказ:

| Галс | Проходов 40 / 80 / 160: тяга, Н | Проходов 40 / 80 / 160: вход min, ° | Проходов 40 / 80 / 160: скачок, % |
|---|---:|---:|---:|

В последней клетке положительного галса на 160 проходах вывод округлён
до 5.0 %, но точное сравнение с прежним пределом даёт `NO-GO`.
На зеркальном галсе уже 80 проходов переводят строку минимального входа
с 1-й на 9-ю, 160 возвращают на 1-ю. Средняя сила и форма не выходят
на один ответ по итерациям; принимать свободный угол на основании одного
числа проходов нельзя.

### Местное давление на расправленной ветви: тоже NO-GO

Последний контроль возвращает экспериментальный профиль на 32 панелях,
но начинает со шкота 5.218 м и переводит его в 9 м за 10 с. Лодка,
решётка и ткань здесь связаны; окно 25…30 с, оба галса, сетки 9/17/33.
В отличие от независимого холодного старта, грубые сетки остаются
расправленными. Тем не менее решение не сходится:

| + | 404.0 / 391.0 / 375.0 | 1.8 / 1.7 / 0.9 | строка 1, 5.135 м / 0.310c | 157.6 % / −0.696c |

На зеркальном галсе у 33 столбцов после 20 с скачок всё ещё

### Изолированный контроль проектора на подвешенной нити: NO-GO

Чтобы не подбирать жёсткость паруса под численную ошибку, тот же
`Cloth.sweep()` проверен отдельно от аэродинамики, кроя, дощечки и шкота.
Нить длиной 1.1 м висит между опорами на расстоянии 1 м под тяжестью;
аналитическая катенария имеет прогиб 0.200301 м. Интегратор Верле,
демпфирование и внутренний шаг 1/60 с взяты из модели ткани. Через 20 с
движение среднего узла за последний шаг менее 0.00005 мм; это не
недостаточно долгий переходный процесс. Длины рёбер проектируются как
односторонние ограничения, без выдуманного модуля ткани.

|---:|---:|---:|---:|---:|---:|
| 9 | 40 | 0.203432 | +1.56 % | 100.103 % | 0.009 |
| 17 | 40 | 0.210062 | +4.87 % | 100.774 % | 0.014 |
| 33 | 40 | 0.237121 | +18.38 % | 103.290 % | 0.030 |
| 65 | 40 | 0.311886 | +55.71 % | 111.199 % | 0.060 |
| 33 | 160 | 0.210159 | +4.92 % | 100.807 % | 0.118 |
| 65 | 640 | 0.210283 | +4.98 % | 100.824 % | 0.960 |
| 65 | 2560 | 0.202257 | +0.98 % | 100.127 % | 3.818 |

В этой простой задаче примерно четырёхкратное увеличение числа проходов
при удвоении числа отрезков удерживает сходную ошибку. На 30 Гц при 40
проходах ошибка 33/65 узлов увеличивается до 52.83/143.53 %, то есть
результат чувствителен и к шагу времени. Замер времени относится только
к изолированному проектору на этом Mac, без полной ткани и браузера.
Аналитическая гладкая катенария не является точным дискретным эталоном,
поэтому таблица не задаёт нового порога приёмки; большой избыток длины
дуги и зависимость от сетки/проходов уже сами нарушают необходимые условия.

Следовательно, увеличение проходов до удобного ответа нельзя считать
исправлением. Нужен более быстро сходящийся решатель ограничений с
контролем остатка на нескольких сетках и шагах времени, а затем отдельная
проверка натяжения шкаторин, шкота и полной формы на обоих галсах.
Успех одной нити не докажет успеха паруса. Штатная ткань и пороги не менялись.

### Кандидат для численного ядра: выпуклая проекция нити

В том же изолированном стенде реализована опытная проекция ADMM:
она минимизирует изменение предсказанных координат при ограничении
`|x[i+1]−x[i]| ≤ длина_звена`. Шаг координат для нити решается
трёхдиагонально, шаг связей — проекцией на круг допустимой длины.
Остановка по первичному и двойственному остаткам `1e-8` м; `rho`
меняет скорость итераций, но не заданную длину или материальные свойства.
Это отдельный код стенда, **не** штатный решатель паруса.

| Длина / хорда | 9 / 17 / 33 / 65 узлов: ошибка прогиба при 60 Гц, `rho=100` | 65 узлов: сред. итераций | Размах среднего узла за последнюю секунду, 65 узлов |
|---:|---:|---:|---:|
| 1.02 | +0.78 / +0.19 / +0.05 / +0.01 % | 87.3 | 0.0002 мм |
| 1.10 | +0.78 / +0.19 / +0.05 / +0.01 % | 53.6 | 0.0001 мм |
| 1.30 | +0.88 / +0.22 / +0.05 / +0.01 % | 68.2 | 0.0001 мм |

При длине 1.10 и 65 узлах результат 30/60/120 Гц округляется одинаково:
прогиб 0.200325 м, ошибка +0.01 %, максимальное растяжение ребра
округляется до 0.000 %. В этих трёх опытах нет шагов, упёршихся в лимит
4096. `rho=10/100` дают тот же прогиб 0.200325 м при нуле лимитных
шагов и средних 124.0/53.6 итерации. `rho=1/1000` дают близкий конечный
прогиб, но имеют 22/11 недоведённых шагов даже при лимите 8192;
доказательством независимости ответа от `rho` они не служат. Для 1.02 и
1.30 на 60 Гц лимит 4096/8192 также даёт ноль недоведённых шагов.
`rho` ускоряет доведение именно в проверенном диапазоне 10…100, не
назначая новый модуль материала. На этом Mac при 1.10 и 65 узлах
наблюдалось около 0.13 мс/подшаг только для одномерной проекции;
браузерный бюджет двумерного полотна этим не доказан.
Опция `--require-converged` возвращает код 1, если хоть один подшаг не
достиг обоих остатков; при `rho=1` и лимите 40 она ловит 1196 из 1200
таких подшагов, тогда как при `rho=100` и лимите 4096 — код 0.

Недоведённый решатель всё ещё опасен: на 65 узлах при `rho=1` и лимите
40 итераций ошибка прогиба −23.38 %, размах за последнюю секунду
176.0 мм. Простая линеаризованная глобальная поправка без ADMM тоже
не годится: при 60 Гц/65 узлах/32 проходах последнее колебание имеет
размах 0.432 мм, а при 30 Гц ошибка прогиба 36.14 %. Малый остаток
длины сам по себе не является положительным результатом динамики.

Положителен пока **только необходимый одномерный численный контроль**.
Дальше нужен тот же критерий остатка и устойчивости для двумерной сети
с реальными ограничениями ткани, дощечкой, свободным шкотовым углом и
несколькими нагрузками; затем сеточная и временная сходимость связанной
аэродинамики на обоих галсах. Порог 5 % и штатный код не менялись.

### Двумерная сеть кроя: дощечка и прямой перенос ADMM

Отдельный стенд `cloth-net-admm.mjs` берёт **те же** узлы, массы,
длины и связи `ck=1` кроя 11×9/17/33. Исходную форму доводит 640
штатными проходами и измеряет её до нового возмущения. Без аэродинамики
и без подмены материальных констант обнаружен геометрический остаток:

| Столбцов | Штатная дощечка: наибольшее растяжение жёсткой связи | Размещение по материальным долям, только стенд |
|---:|---:|---:|
| 9 | 5.4215 % | 0.0011 % |
| 17 | 5.4215 % | 0.0030 % |
| 33 | 5.4215 % | 0.0071 % |

Расстояние концов и прямая связь дощечки равны 0.250000 м. Однако штатная
формула ставит промежуточные узлы по плоской `px/rowW`, а не по доле
материала: у 9 столбцов одно ребро длиной покоя 0.031250 м получает
0.032944 м, у 33 — 0.007813 → 0.008236 м. Это тот же выход `t>1`
у предпоследнего узла, который замечен выше. Принуждение всех жёстких
связей без дощечки устраняет растяжение, но уводит верхние узлы от её
штатной прямой на 11.86/13.13 мм (9/33 столбца). Это конфликт **текущей
формулы размещения и ограничений на данном состоянии**, а не доказанная
невозможность кроя. Материальные доли снимают именно этот численный дефект;
предыдущий связанный опыт на зеркальном галсе всё ещё дал скачок тяги
8.6 % при пределе 5 %, поэтому штатно переключать вариант нельзя.

На материальной дощечке и одинаковом дополнительном смещении свободных
узлов до 0.1 м для 11×33 исходное максимальное растяжение жёстких связей
1.404 %. Последовательная проекция **только этих связей** дала после
40/160/640 проходов 0.290/0.017/менее 0.001 % и сохранила близость к
дощечке около 0.03 мм. Прямой перенос ADMM на граф с CG-решением шага
координат при множителе `rho` 1/10/100 от медианной массы за 400
итераций не достиг остатка `1e-8`: максимальная невязка первичного или
двойственного шага порядка `5e-6/1e-5/6e-4` м, верхние узлы ушли от
дощечки на 0.98/2.45/2.81 мм, время 72/86/93 мс против примерно
14 мс для 640 последовательных проходов на этом Mac. В ADMM не включены
мягкие связи перекоса, изгиб, жёсткая дощечка и свободный шкот;
сравнение здесь относится лишь к той же подсети `ck=1`. Наивный
двумерный перенос одномерного успеха — **NO-GO** по остатку, цене и
неполной постановке. Нужен совместный решатель с точной кинематикой
дощечки и проверкой полной динамики, а не повышение числа итераций
лишь ради совпадения одной геометрии. Runtime не менялся.
Опция `--require-converged` для этой клетки возвращает код 1 именно
из-за недостигнутого остатка, даже когда печатаемое растяжение округляется
почти до нуля.

Следующий изолированный опыт устранил один недостаток самого тестового
ADMM: при `--rigid-board --board-material` верхние промежуточные узлы
вообще исключены из независимых степеней свободы и заданы линейно
двумя концами дощечки. Теперь её геометрический остаток **ровно 0**,
включая после проекции, а не исправлен задним числом. На той же форме,
смещении 0.1 м и `rho` равном медианной массе процедура достигла
первичной невязки `<1e-8 м` и тогдашней реберной двойственной меры
`<1e-8 кг·м` без срыва внутреннего CG:

| Сеть | Внешних итераций ADMM | Время одной статической проекции, мс | Верх / остаток жёстких связей |
|---:|---:|---:|---:|
| 11×9 | 2684 | ~96 | 0 мм / `<1e-8` м |
| 11×17 | 2356 | ~167 | 0 мм / `<1e-8` м |
| 11×33 | 2289 | ~310 | 0 мм / `<1e-8` м |

При прежнем лимите 400 на 11×33 точная дощечка уже была соблюдена,
но первичный/двойственный остатки оставались `2.37e-6/1.15e-5` м;
проверка `--require-converged` вернула бы код 1. Таким образом, нынешняя
выпуклая постановка может совместить дощечку и жёсткие связи, но **не
годится для realtime по цене** и ещё не описывает мягкие связи, шкот и
нестационарную ткань. Стоимость здесь относится к одной проекции одного
возмущённого снимка, без аэродинамики, браузера и нескольких подшагов.
Увеличением лимита лишь доказана достижимость, а не пригодность метода.

Проверен и перенос состояния ADMM между последовательными проекциями:
одна и та же исходная сеть получает 60 заданных малых изменений формы
`0→0.1→0` м; каждую цель решают холодным и тёплым стартом с **тем же**
тогдашним реберным критерием и точной дощечкой. Это кинематическая проба стоимости,
а не динамика с ветром, шкотом или инерцией.

| Сеть | Внешних итераций за 60 проекций: холодный / тёплый | Время, с: холодный / тёплый | Тёплый на одну проекцию | Наибольшая разность координат двух решений |
|---:|---:|---:|---:|---:|
| 11×9 | 128409 / 102235 | 6.04 / 4.42 | ~74 мс | 0.0025 мм |
| 11×17 | 104188 / 85492 | 14.24 / 8.41 | ~140 мс | 0.0045 мм |
| 11×33 | 96089 / 77857 | 23.07 / 14.90 | ~248 мс | 0.0086 мм |

Ни один из 360 холодных или тёплых кадров не упёрся в лимит 4000,
геометрический остаток дощечки нулевой. Тёплый старт ускоряет мелкие
шаги, но остаётся намного дороже 16.7 мс всего кадра при 60 Гц ещё
**до** мягких связей, аэродинамики и лодки. При 20 более крупных шагах
на 11×33 он, наоборот, занял 6.05 против 5.86 с холодного старта;
считать перенос состояния универсальным ускорением нельзя. Это
вычислительный NO-GO нынешнего ADMM, не физический отказ ткани.

### Локальный штраф связей: численное ускорение без физической подмены

В диагностическом ADMM проверен штраф `rho_k = 2/(w_i+w_j)` на каждой
связи (`w` — обратная масса узла), умноженный на тот же безразмерный
коэффициент 1. При равных массах свободных концов это масса одного узла;
материальные длины и силы не менялись. Исправлен и измеритель остановки:
первичная невязка — максимальная длина `Ax−z` в метрах, двойственная —
`AᵀR(zⁿ−zⁿ⁻¹)` **в независимых координатах после исключения дощечки**, в
`кг·м`. Обе численно ограничены `1e-8` в своих единицах; внутренний CG
не должен упираться в лимит. Ранее приведённые таблицы ADMM с единым
`rho` использовали **реберную**, а не собранную двойственную меру;
их времена и итерации оставлены как история опыта, но не являются
сертифицированными по исправленному измерителю. Сравнение на одном
возмущённом снимке с одинаковой постановкой и исправленной остановкой:

| Сеть | Единый `rho`: итераций / мс | Локальный `rho_k`: итераций / мс | Максимальная разность координат двух доведённых решений |
|---:|---:|---:|---:|
| 11×9 | 3382 / 156.5 | 288 / 19.6 | 0.000207 мм |
| 11×17 | 3257 / 278.6 | 1196 / 78.3 | 0.000193 мм |
| 11×33 | 3495 / 564.0 | 480 / 67.9 | 0.000206 мм |

Времена одного запуска зависят от прогрева JS; сокращение числа итераций
11×33 — `3495→480`, не постулированное ускорение всего симулятора. Для
локального варианта 11×33 первичная/двойственная невязки
`9.62e-9 м / 7.17e-9 кг·м`, дощечка точно прямая, лимитных CG нет.
Уменьшение множителя до 0.1 **не проходит** исходную остановку даже за
4000 итераций: `1.42e-7 м / 7.48e-10 кг·м`, 128 связей длиннее
допуска 10 нм. Множитель 10 проходит, но медленнее (1145 итераций).
Подгонять множитель для ответа нет смысла: он влияет лишь на скорость.

На 60 последовательных целях `0→0.1→0` м с исправленной двойственной
невязкой локальный вариант довёл все кадры. Тёплый старт занял
`0.490/1.809/3.953 с` на 11×9/17/33, то есть
`8.2/30.1/65.9 мс` на одну проекцию; для 11×33 единый `rho` занял
`25.151 с` (`419.2 мс/кадр`). На 11×33 максимальное различие
холодного и тёплого решений `0.0002 мм`. Ускорение существенно, но
**11×17 и 11×33 всё ещё не помещаются в 16.7 мс целого кадра**,
а 11×9 оставляет слишком мало времени для остальных сил и лодки.
Это по-прежнему лишь кинематическая проекция жёстких связей `ck=1`:
мягкие связи, свободный шкотовый угол, инерция, давление и перенос
моментов лодке отсутствуют. Поэтому это численный кандидат, а не
положительный результат по физическому генакеру или разрешение менять
runtime.

### Свободный угол и односторонний шкот в той же численной проекции

К диагностической выпуклой задаче добавлен свободный шкотовый узел и
ограничение `|x_шкот−x_обух| ≤ L_шкота`, с отдельной переменной ADMM.
Дощечка остаётся точной, жёсткие связи `ck=1` и остановка по полной
первичной/двойственной невязкам не меняются. При рабочей длине
`5.218 м` исходное расстояние до обуха `5.214…5.215 м`. Смещение
только шкотового узла на 0.1 м наружу активирует шкот: для 11×9/17/33
получено 302/1222/479 итераций с локальным штрафом; итоговая длина
`5.218000 м`, нулевое превышение и положительный множитель
`0.1154/0.04968/0.02274 кг·м`. Общий штраф даёт те же координаты с
разностью не более `0.000204 мм`, но требует 3418/3251/3467 итераций.
При шкоте `9 м` на 11×33 длина после проекции `5.296810 м`, множитель
**ровно ноль**. У стенда есть проверка ожидаемой ветви: правильные
`--expect-sheet=taut/slack` дают код 0, намеренно перепутанные — код 1.
В 60 последовательных кинематических целях `0→0.1→0 м` на 11×33
тёплый/холодный расчёт не разошёлся по ветви ни в одном кадре:
натянутый шкот в 57/60, максимальная разность координат `0.0007 мм`,
все кадры доведены, превышение длины нулевое. Это не история реального
травления шкота: менялась предсказанная координата угла, не `L_шкота`.

Однако одинаковое смещение *одного узла* не является одинаковой
физической силой при сгущении: его масса падает. Поэтому отдельно задана
одна и та же точечная сила `20 Н`, прогноз
`x* = x + F·Δt²/m_шкотового_узла`, остальные узлы не возмущены.
Множитель ограничения, поделённый на `Δt²`, есть реакция в ньютонах
именно **этого одношагового проектора**:

| Δt, с | 11×9 | 11×17 | 11×33 | 11×65 |
|---:|---:|---:|---:|---:|
| 1/30 | 16.20 Н | 18.17 Н | 19.05 Н | 19.69 Н |
| 1/60 | 4.81 Н | 12.69 Н | 16.18 Н | 18.75 Н |
| 1/120 | 0 Н | 0 Н | 4.73 Н | 14.99 Н |

Все эти проекции достигли прежних численных допусков без лимита CG,
дощечка точна, длина шкота не превышена. При `1/120 с` на 11×9/17
шкот остаётся слабым (`5.215956/5.216897 м < 5.218 м`) и множитель
равен нулю. Это **не** проверка сходимости по времени при одном и том же
физическом горизонте: во всех клетках сделан ровно один шаг от исходника
с миллиметрами слабины. Она доказывает, что реакция переключается
односторонне, и одновременно показывает, почему по ней нельзя заключить
о натяжении в полёте. Нужна многокадровая динамика с одинаковой историей
нагрузки/трима и измерением натяжения после выхода из начального перехода.
Мягкие связи перекоса, изгиб, давление, движение лодки и перенос реакции
через обух в её моменты здесь ещё отсутствуют. Штатный путь не изменён.

### Многокадровая проба на настоящей распределённой нагрузке

Диагностический проектор получил режим нескольких подшагов на одном
физическом горизонте. Прогноз —
`x* = x + exp(−6Δt)·(x−x_пред) + Δt²F/m`, после него та же точная
проекция жёстких связей, дощечки и
шкота. Начальная скорость нулевая. Для одинакового входа лодка и
полоски проходят опорные 30 с при TWA 140°/TWS 6 м/с, затем на
первой форме каждой ткани берутся неподвижные понодальные давления и
нормали. Суммы сил 11×9/17/33: `158.557/−171.826/25.068`,
`158.531/−171.818/25.069`, `158.500/−171.782/25.064 Н` —
расхождение суммы по сеткам менее 0.04 %. Длина шкота `5.218 м`.
Наибольшее ускорение свободного узла тоже практически одинаково:
`14.332/14.251/14.150 м/с²`, свободный прогноз на `1/30 с`
`15.925/15.834/15.722 мм`. Поэтому разницу сходимости нельзя
списать на резко разную амплитуду нагрузки при сгущении.
Это фиксированная *аэродинамическая нагрузка* для проверки механики,
не связанное давление и не измеренная модель отрыва.

Первая проба с постоянной точечной силой **вдоль шкота** оказалась
тривиальной: после натяжения на 11×9 шкот принимал все `20.000 Н`, а
середина полотна оставалась неподвижной. Она подтверждает реакцию связи,
но не испытывает динамику ткани. При распределённом давлении результат
совсем другой:

| Сеть, штраф, лимит | Первый шаг 1/30 с: первичная / двойственная невязка | Исход |
|---|---:|---|
| 11×9, локальный ×1, 4000 | `3.55e-6 м / 6.21e-9 кг·м` | недоведён, код 1 |
| 11×9, локальный ×100, 8192 | доведён | 6 шагов за 0.2 с физического времени потребовали 43559 итераций и 2.46 с вычисления |
| 11×17, локальный ×100, 8192 | `2.72e-7 м / ~1e-11 кг·м` | недоведён, код 1; первый шаг ~0.8 с |
| 11×33, локальный ×100, 8192 | `2.70e-7 м / 1.60e-12 кг·м` | недоведён, код 1; первый шаг 1.45 с |

Уменьшение шага до `1/120 с` при ×100 не устранило блокер на 11×17/33:
после 8192 итераций первый шаг имеет `2.50e-8 м / 3.66e-7 кг·м` и
`1.45e-8 м / 6.29e-13 кг·м`. Прежние допуски
`1e-8 м / 1e-8 кг·м` не менялись. Поэтому сравнение летящей формы и
реакции на общем физическом горизонте **не состоялось**: использовать
недоведённые шаги для сеточной/временной сходимости было бы ложным
положительным результатом. Даже клетка 11×9, которая доводится при ×100,
стоит намного дороже realtime. Нужен численно иной полный решатель ткани,
а не выбор слабого давления, грубой сетки либо удобного шага. Режим
по-прежнему не содержит мягких связей, изгиба и обратной связи с лодкой;
его NO-GO относится прежде всего к нынешнему численному ядру под нагрузкой.

### Второй численный кандидат: ускоренный двойственный prox — NO-GO

Ту же выпуклую проекцию проверили независимо от ADMM в двойственных
импульсах связей. После исключения координат узлов двойственная задача —
квадратичная форма плюс `Σ L_k|λ_k|`; проксимальный шаг есть векторная
усадка. Диагональные шаги по массе и топологии ограничены нормой оператора:
сначала строгой суммой строк, затем независимо 80 шагами степенного
метода с коэффициентом безопасности 0.9. Остановка требует прежнего
геометрического допуска `1e-8 м`, изменения двойственной переменной
`1e-8 кг·м` и проксимальной KKT-невязки `1e-8 м`. Материал, сила, шкот
и дощечка не менялись.

На одном статическом возмущении 11×9 с точной дощечкой решение
совпало с доведённым ADMM в пределах `0.000066 мм` по координате,
но двойственный метод потребовал `4060 итераций / 100 мс` против
`288 / 18 мс` у ADMM. Со свободным натянутым шкотом разность
`0.000087 мм`, разность множителя `3.86e-15 кг·м`, цена
`5129 / 127 мс` против `302 / 23.5 мс`. То есть формула и знаки
проверены независимым решателем, но цена хуже. На 11×17 и 11×33 даже
**статический** снимок не дошёл до допуска за 8192 итераций:
первичная невязка `4.25e-8/6.83e-7 м`. Спектральная оценка вместо
суммы строк меняет предел шага лишь с `57.918→55.065` и
`112.189→105.883`: проблема не в чрезмерно осторожной оценке шага.

На том же замороженном распределённом давлении и свободном шкотовом
угле первый шаг `1/30 с` снова не доведён ни на одной из сеток
11×9/17/33: после 8192 итераций первичная невязка
`2.57e-8/1.23e-7/5.94e-7 м`, время одного шага
`252/610/1056 мс`. Проксимальная KKT-невязка тоже выше `1e-8 м`.
Таким образом, простой ускоренный двойственный метод не снимает
вычислительный блокер и не даёт оснований анализировать сеточную или
временную сходимость недоведённой формы. Он оставлен только в стенде как
отрицательный контроль. Runtime и пороги не менялись.

### Плечо жёсткой дощечки: численная сходимость есть, физического GO нет

Трассировка невязок при `rho-local ×100` показала конкретное узкое место:
на 11×17 после 8192 итераций под замороженным давлением единственная
растянутая более чем на 10 нм жёсткая связь идёт от галсового угла к
первому внутреннему узлу жёсткой дощечки (`0→171`). Её плечо в
исключённой координате дощечки — `1/16`; превышение `0.000272 мм`
почти целиком объясняет первичную невязку `2.72e-7 м`. Двойственная
невязка уже `5.58e-12 кг·м`. Нормировка штрафа этой связи на квадрат
плеча меняет перекос: первичная невязка падает до `6.55e-9 м`, но
двойственная растёт до `2.99e-6 кг·м` на лимите итераций. Это
диагностика обусловленности, а не изменение ткани.

Промежуточная нормировка на **первую** степень плеча при той же
нагрузке, материале, дощечке, шкоте `5.218 м` и неизменных допусках
`1e-8 м / 1e-8 кг·м` довела все шесть шагов за `0.2 с` на 11×9/17/33
при `1/30 с` и на 11×17/33 при `1/120 с`. На первом шаге 11×17/33
требовались `6225/8158` итераций; последняя сетка почти исчерпывает
лимит `8192`. Для 0.2 с цена и отклик таковы:

| Сеть / шаг | Итераций суммарно | Время проекций | Реакция шкота в 0.2 с | Средняя реакция 0.1…0.2 с | x середины полотна в 0.2 с |
|---|---:|---:|---:|---:|---:|
| 11×9 / 1/30 с | 43477 | 1.916 с | 2.873 Н | 2.998 Н | 5.146982 м |
| 11×17 / 1/30 с | 42744 | 4.486 с | 1.999 Н | 1.840 Н | 5.146878 м |
| 11×33 / 1/30 с | 41853 | 7.461 с | 1.847 Н | 1.783 Н | 5.145731 м |
| 11×17 / 1/120 с | 143506 | 11.794 с | 1.841 Н | 1.756 Н | 5.145434 м |
| 11×33 / 1/120 с | 140242 | 24.324 с | 1.741 Н | 1.724 Н | 5.144536 м |

Это **положительный контроль сходимости проектора** на коротком
горизонте, но не положительный итог для генакера. Реакция шкота на
11×9 и 11×33 при `1/30 с` отличается на 1.026 Н; даже между
11×17 и 11×33 при `1/120 с` — на 0.100 Н в конечной точке.
Уменьшение шага на 11×33 меняет её на 0.106 Н. Установившегося
режима за 0.2 с нет; внешнее давление заморожено, мягкие связи и
изгиб отсутствуют, обратная связь с лодкой отключена. Порядка
`0.5…1 с` вычисления на каждый шаг также несовместимо с realtime.
Нельзя трактовать эти числа как проверенную силу шкота, тем более
подгонять по ним полярную тягу. Нужны более эффективный решатель,
полная связанная физика и сравнение сетки/шага на осмысленном
физическом горизонте. Штатный код, поляра и пороги не менялись.

### Сверхрелаксация ADMM: малого ускорения недостаточно

На том же жёстком проекторе с нормировкой плеча в первой степени
проверена сверхрелаксация на заранее выбранных `α=1.2/1.5/1.8`;
исходное `α=1`. В обновлении связей используется
`α(Ax)+(1−α)z_старое`; физические ограничения, нагрузка, штрафы,
решение линейного шага и оба допуска `1e-8` не изменены. Критерий
первичной невязки по-прежнему вычисляется по настоящему `Ax−z`, а не
по сверхрелаксированной промежуточной переменной.

При `α=1.2` на горизонте 0.2 с / 30 Гц сетки 11×17 и 11×33
довелись: суммарные итерации сократились соответственно
`42744→37873` и `41853→36138`. Реакция шкота в 0.2 с осталась
`1.999/1.847 Н` с точностью вывода, середина полотна также совпала
в пределах показанных шести знаков. Но 11×33 потребовала `7.52 с`
вычислений против `7.46 с` при `α=1`: выигрыша в цене кадра нет.
При `α=1.5` и `1.8` уже исходная проекция 11×17 не достигла
двойственного допуска за 8192 итерации: `6.61e-7` и
`7.94e-7 кг·м` при первичной невязке `1.69e-9` и `6.17e-9 м`.
Это **NO-GO для сверхрелаксации как решения проблемы цены**.
Диагностический параметр оставлен для воспроизведения; штатная
модель не менялась.

### Покоординатный двойственный разогрев: быстрее, но ещё не realtime

Независимый кандидат минимизирует ту же выпуклую двойственную задачу
**точно по одной векторной связи за раз**. Усадка импульса связи и
массовое обновление затронутых узлов не требуют глобального линейного
шага ADMM; направление обхода чередуется. Множители этого метода
переносятся в масштабированные двойственные переменные ADMM, после
чего прежний проектор доводит ту же задачу до допусков. В гибридном
контроле 256 предварительных проходов — численный параметр, не новая
жёсткость ткани или порог.

На статическом возмущении 11×9 с натянутым шкотом самостоятельный
покоординатный метод довёл первичный/двойственный/KKT остатки до
`3.50e-9 м / 9.96e-9 кг·м / 3.50e-9 м` за 499 проходов и 23.4 мс.
Контрольный ADMM на той же задаче потребовал 7792 итерации и 252.3 мс;
максимальная разность формы `0.000634 мм`, разность множителя шкота
`1.22e-12 кг·м`. Но **сам по себе** покоординатный метод при
замороженном давлении не доводит первый шаг 1/30 с за 8192 прохода:
первичная невязка на 11×9/17/33 равна
`3.54e-7/2.40e-7/1.11e-6 м`. Поэтому самостоятельная замена ADMM —
NO-GO; её статическая скорость не является свидетельством динамики.

Гибрид с 256 предварительными проходами и локальным ADMM `×100`,
нормировка плеча дощечки в первой степени, прежние допуски и те же
шесть либо 24 шага под замороженной нагрузкой:

| Сеть / шаг | Время проекций ADMM → гибрид | Итераций гибрида суммарно | Реакция шкота в 0.2 с ADMM → гибрид |
|---|---:|---:|---:|
| 11×9 / 1/30 с | 1.916 → 0.648 с | 15161 | 2.873 → 2.873 Н |
| 11×17 / 1/30 с | 4.486 → 1.505 с | 21593 | 1.999 → 1.999 Н |
| 11×33 / 1/30 с | 7.461 → 3.582 с | 23598 | 1.847 → 1.847 Н |
| 11×17 / 1/120 с | 11.794 → 1.833 с | 22690 | 1.841 → 1.844 Н |
| 11×33 / 1/120 с | 24.324 → 4.956 с | 37853 | 1.741 → 1.756 Н |

Все гибридные шаги достигли прежних невязок и не нарушили жёсткие
связи, шкот и дощечку. На 1/120 с небольшое отличие силы при одинаковом
геометрическом допуске показывает, что точность реакции следует
проверять отдельно; деление множителя на `Δt²` усиливает малую разницу.
Даже лучший из этих результатов на 11×33 требует 3.582 с вычислений
на 0.2 с физического времени при 30 Гц, а физика по-прежнему
hard-only с замороженной аэродинамикой. Это **положительный численный
разогрев**, не GO для реального времени или правдоподобия управления.
Штатная ткань, поляра и пороги не менялись.

На более длинном, но всё ещё **замороженном** аэродинамическом входе
гибрид довёл все 30 либо 120 подшагов за 1 с на 11×17 и 11×33:

| Сеть / шаг | Реакция шкота в 0.5 → 1.0 с | Средняя / RMS за 0.5…1.0 с | x середины полотна в 1.0 с | Время проекций |
|---|---:|---:|---:|---:|
| 11×17 / 30 Гц | 3.633 → 5.229 Н | 4.424 / 0.471 Н | 5.208317 м | 5.888 с |

шага на 1 с ещё не показана. Сила не проходит обратную связь с
аэродинамикой и корпусом; дальнейшее продление такой же замороженной
пробы не заменит связанный опыт.

### Пересчёт давления на новой форме при неподвижной лодке

Чтобы проверить первую половину связи «ткань → аэродинамика → ткань»
без второй реализации нагрузки, из `Cloth.advance` выделен
`forcesAt`: тот же расчёт понодального давления, площади, нормали,
тяжести и аэродинамического затухания до перемещения узлов. Штатный
`advance` вызывает его без изменения порядка действий. Побайтовый
SHA-256 отпечатка `scripts/golden.mjs` до/после рефакторинга одинаков:
`e96ffa88442fbd33dee87ab6c45257ed9cef15564c10915cf5be533e51e54997`;
`tests/cloth.test.mjs` завершился «всё ок».

Опытный экземпляр ткани становится геометрией решётки, но его штатный
PBD-шаг в этом стенде выключен; узлы двигает тот же доведённый гибрид.
Решётка и её пелена пересчитываются на каждой новой форме, лодка пока
неподвижна. Режим `recomputed-pressure` берёт только нормальное давление;
`full-cloth-load` добавляет из *той же* функции тяжесть ткани и
аэродинамическое затухание. Материал по-прежнему hard-only: мягкие
связи и изгиб ещё не перенесены в гибридную проекцию.

На 0.2 с при 30 Гц все три сетки доведены с прежними допусками:

полной). Это отрицательный результат для трактовки прежней

### Первый связанный шаг с движущейся лодкой

В диагностическом режиме `boat-coupled` после доведённого шага ткани
штатный `Boat.step` получает её новую геометрию, обновляет решётку,
пелену и корпус, затем `forcesAt` сохраняет полную нагрузку ткани для
следующего шага. У опытного экземпляра выключено только его штатное
PBD-перемещение; материал и гибридный проектор — те же, что выше.
Это явное слабое сопряжение с задержкой на один шаг, без внутренней
итерации ткани и потока. Курс удерживается тем же рулевым законом,
которым прогревались опорные 30 с. Исходное состояние лодки:
`2.8689 м/с`, курс `−40.756°`, крен `−9.307°`.

На 0.2 с / 30 Гц сетки 11×9/17/33 проходят прежние допуски;
конечная реакция шкота `2.723/1.863/1.689 Н` против
`2.721/1.862/1.688 Н` при неподвижной лодке. Движение за эти
0.2 с слишком мало для проверки управления: ход достигает лишь
`2.8700 м/с`, курс `−40.754°`, крен `−9.308°`.

| Сеть / шаг | Шкот в 0.5 → 1.0 с | Ход / курс / крен в 1.0 с | Fx/Fy всех парусов в 1.0 с |
|---|---:|---:|---:|

| 11×33 / 30 Гц | 2.817 → 4.544 Н | 2.8789 м/с / −40.744° / −9.336° | 303.147/−170.024 Н |
| 11×17 / 120 Гц | 3.175 → 4.445 Н | 2.8783 м/с / −40.745° / −9.328° | 302.394/−170.488 Н |
| 11×33 / 120 Гц | 2.704 → 4.365 Н | 2.8783 м/с / −40.745° / −9.328° | 302.383/−170.502 Н |

На 11×33 уменьшение шага меняет конечную реакцию шкота на

за короткую секунду различается лишь на `0.0006 м/с` из-за инерции

Сопряжение технически проходит, но физический и realtime GO не дан.

## Связанный опыт: отрицательный результат для штатного включения

Четыре клетки прежнего аудита, TWS 6 м/с, окно 25…30 с после независимого
старта при 3 м/с. Здесь положительный галс соответствует прежнему аудиту.

| TWA / шкот | Тяга без модели / 32 панели, Н | Нагрузка первых двух узлов / вся, без модели / 32 панели | Минимальный угол входа, 16 / 32 / 64 панели |
|---|---:|---:|---:|
| 140° / 8.5 м | 447.6 / 442.1 | 18.9 / 3.2 % | +23.6 / +23.8 / +23.8° |
| 140° / 9.0 м | 404.8 / 389.9 | 18.6 / 21.0 % | −12.0 / −5.0 / +2.2° |
| 150° / 8.5 м | 254.9 / 255.0 | 18.9 / 22.9 % | +23.6 / +23.6 / +23.6° |
| 150° / 9.2 м | 295.1 / 295.8 | 19.1 / 13.5 % | +23.7 / +23.7 / +23.7° |

У 140°/8.5 м сила первого узла отрицательна: −9.2 Н в сумме по высоте,
хотя общая нормальная нагрузка положительна. Локальная разгрузка теперь
получается из решения. Однако знак заворота 140°/9.0 м **не сошёлся** по
числу панелей: по нему пока нельзя учить пользователя работе шкотом.

При 32 панелях переход с 30 на 60 Гц дал для 140°/9.0 м угол −5.0 → −4.8°,
тягу 389.9 → 389.0 Н, скорость 6.915 → 6.922 уз. Это существенно меньше
разницы по панелизации. На другом галсе при 32 панелях та же клетка дала
355.7 Н против штатных 410.3 Н, угол +19.8° и скачок общей тяги **8.7 %**
при прежнем пределе **5 %**. Существующая асимметрия штатной лодки есть
(404.8/410.3 Н), но новым режимом она усилилась. Порог не изменён.

Парный манёвр `140° / 8.5→9.0→8.5 м` при 16 панелях, с начальными ходами
3.00/3.05 м/с, также не подтвердил правильный сигнал: при травлении тяга
убывает на 63.1/62.5 Н относительно контроля, но минимальный угол входа
остаётся +19.7° на обоих стартах. Заворот из независимого установившегося
старта нельзя выдавать за воспроизведённую последовательность управления.

Время 30-секундной симуляции на этом Mac: около 1.0…1.9 с штатно,
1.4…2.3 с с 32 панелями, 2.4…3.4 с с 64. Это CPU-стенд без рендера,
не гарантия браузерного бюджета кадра.

Следующее развитие требует отделить ошибки локального профиля на ломаной
геометрии от связанной неустойчивости ткани, на замороженных одинаковых формах.
Для полноценного отрывного режима понадобятся нестационарная циркуляция и
сход с передней кромки, согласованные с общей пеленой, а также независимый
профиль давления при изменении шкота. Наблюдаемый заворот не заменяет этих
проверок. Текущий прототип сохраняется для воспроизводимого сравнения;
автоматическое включение, калибровка поляры по нему и изменение порогов
не допускаются этим результатом.
