# Измерение формы паруса

Методика для независимой проверки проекта, ткани и летящей поверхности.
Прежние численные сравнения относятся к своим исходным режимам; актуальные
ограничения формы — в [состоянии](../project/status.md).

## Сравниваемые объекты

Сохраняйте отдельно проектную 3D-поверхность, ненагруженные длины ткани,
летящую поверхность и изображение после декоративных добавок. Геометрические
длины кромок, прямые расстояния между концами и хорды сечений не равны друг другу.

Станция независимого обмера может соединять равные доли длины передней и
задней кромки. Горизонтальный ряд `Cloth` не является такой станцией:
сначала постройте одинаковое определение сечения и его плоскости.
Ссылки на измерения — [источники](../research/sources.md).

## Величины

| Величина | Как интерпретировать |
|---|---|
| Хорда | Прямое расстояние между концами сечения |
| Длина ткани | Длина полилинии/дуги по материалу; проверять относительно кроя |
| Выпуклость и её положение | Расстояние от хорды и координата максимума; указывать нормировку |
| Углы входа и выхода | Касательные у краёв; фиксировать направление отсчёта и сторону |
| Изменение направления профиля | Отличать общий плавный изгиб от местного залома |
| Возврат назад и выворот | Измерять участки поверхности, а не только знак суммарной силы |
| Длины кромок и площадь | Сравнивать в полёте и в материальной геометрии |
| Твист | Разница ориентации станций, определённых одинаково |
| Натяжение/слабина верёвки | Односторонняя реакция; коррекция положения сама по себе не измеренная сила |
| Сила, момент и центр давления | Получать из той нагрузки, которая действительно приложена |

У девяти узлов может быть ограничена оценка локальной касательной входа.
Увеличение аэродинамических панелей на той же кусочно-линейной форме не
добавляет независимой информации о геометрии ткани.

## Критерии и сходимость

Не требуйте универсально положительный вход, однозначную проекцию на хорду
или отсутствие подвёрнутого переднего участка: существуют измеренные режимы,
в которых они неверны. Критерий зависит от наблюдаемого состояния и данных.
Не принимайте вывернутую большую складку за успешный небольшой заворот.

Проверяйте одинаковый крой, закрепления и нагрузку на вложенных сетках,
разных шагах и итерациях. Сошедшаяся координата центра не заменяет
сходимость всей формы, энергии, работы и остатка сил.

`Cloth.rowShape()` принимает индекс строки, не долю высоты. Для проверки
10–90% используйте соответствующий ряд по числу строк: прежний ошибочный
вызов измерял только нижнюю часть и дал неверную интерпретацию.
Основной диагностический пример — `tests/gennaker-trim-sequence.mjs`.

Результат описывается командой, ревизией, режимом ткани/давления, координатами
станций, окном времени и численными величинами. Картинка дополняет измерение,
а не заменяет его.
