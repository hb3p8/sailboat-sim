# Стоимость исследовательского движения ткани

## Вопрос и границы

Первое ускорение уменьшило стоимость +/41×33 с 1014 до 522 с с точным
совпадением всех сохранённых физических полей. Интерактивная скорость
не достигнута; условия и ограничения измерения приведены ниже.

После проверки первой секунды на 41×33 посадка и 1 с движения занимают
1013.69/870.20 с для двух сторон ветра. Это мешает дальнейшему уточнению
и интерактивному обучению. Здесь измеряется стоимость решения прежнего
уравнения; материал, крой, нагрузка, h и физические допуски не меняются.
[Условия и формы](cloth-material.md#первая-секунда-на-трёх-полных-сетках)
сохранены отдельно. Скорость исследовательского стенда не является FPS браузера.

## Профиль средней сетки

2026-10-02, Apple M5 arm64, Node.js v26.5.0, чистый `d3d25d9`, прежний пакет
`dcaedc8b176e88251fd5ea3d8b869bc4deb366199f230c3e7739f9f6034b8f5a`.
Профиль V8 записан для +/21×17, посадка 40 шагов отдельно и затем 1 с,
h=1/60 с, предел 80, назначенные K/G/B, постоянный общий вход.

```sh
node --cpu-prof --cpu-prof-dir=out/acceptance --cpu-prof-name=implicit-joined-baseline21.cpuprofile tests/cloth-frozen-aero-grid.mjs --tack=1 --sheet=9 --iter=80 --fixed-load --grids=21x17 --mechanics --rigid-board --energy-material --implicit-motion --hold-cut-clew --cut-nesting --shared-input --continuous-cut --joined-cut-profile --seconds=1 --out=out/acceptance/implicit-joined-profile-baseline21.json
```

| Функция | Собственное время по выборкам, с | Доля всех выборок процесса |
|---|---:|---:|
| Прямой/обратный ход `bandFactor`, возвращённая функция | 10.920645 | 51.15% |
| Разложение матрицы `bandFactor` | 3.588487 | 16.81% |
| Остальная часть `direction` | 1.231537 | 5.77% |
| Сборка мусора | 0.320044 | 1.50% |

Сумма длительностей выборок процесса 21.349305 с; таймер ткани внутри записи
19.278656 с. Выборки включают подготовку опорной лодки и импорт модулей;
собственное время не включает дочерние функции. Это измерение V8, не точная
разметка всех фаз отдельного шага. Линейное решение занимает около 68%
выборок, поэтому первое ускорение направлено на него.

Сводка воспроизводится `scripts/cloth_cpu_profile.mjs`; запись содержит SHA256
входного профиля и инструмента. Одинаковая функция в разных ветвях стека
объединяется по имени/источнику/строке, дочернее время не суммируется с её
собственным. После первого ускорения прямой/обратный ход занимает 5.669451 с
(36.28%), разложение 3.215117 с (20.57%) из 15.626339 с выборок процесса.
В исходном профиле встречается один интервал −1 мкс, в новом три таких
интервала. Исходные знаки сохранены; число и сумма модулей отрицательных
интервалов записаны отдельно, а не скрыты округлением или удалением.

```sh
node scripts/cloth_cpu_profile.mjs --input=out/acceptance/implicit-joined-baseline21.cpuprofile --out=out/acceptance/implicit-joined-baseline21-profile-measured.json
node scripts/cloth_cpu_profile.mjs --input=out/acceptance/implicit-joined-linear-local21.cpuprofile --out=out/acceptance/implicit-joined-linear-local21-profile-measured.json
node tests/cloth-cpu-profile.test.mjs
```

Независимый контроль использует известную двухсекундную шкалу: 75% решения,
25% подготовки, повтор одной функции в разных узлах. Проверены также
сохранение отрицательного интервала, отказ неполной шкалы, неизвестного узла,
нечислового интервала и повторного идентификатора.

## Сохранение арифметики при ускорении

В `tests/lib/cloth-linear-solve.mjs` индексы строки и границы цикла вычисляются
один раз; указатели в полосе меняются целочисленным шагом. Промежуточная
сумма прямого/обратного хода хранится в числе, затем один раз записывается
в массив. Порядок умножений и вычитаний, разложение, система уравнений,
набор связей и условия остановки сохранены.

Предварительные опыты имеют `dirty:true` и отпечатки проверяемой реализации;
им не приписывается чистый коммит модели. У +/21×17 с тем же профилированием
стоимость ткани уменьшилась 19.278656→13.578886 с. У −/11×9 и −/21×17
без профилирования измерено 1.479659/12.315264 с. Во всех трёх случаях точно
совпали с прежними записями поля `initialInput`, `referencePositionsM`,
`finalPositionsM`, `warmup`, `energyMotion`, `samples`, `mechanics`, `constraints`.
Проверка сравнивает все сохранённые числа, не только силуэт и конечную энергию.
Однократные времена полного опыта не являются устойчивой оценкой ускорения.

Независимый `cloth-implicit-motion.test.mjs` дополнен матрицами с известным
решением: диагональ, полосы 161/305, крайние строки и ширина больше размера
матрицы. Прежние малые контроли сохранены. Широкие матрицы построены из
диагонально преобладающего L; заданное решение ограничено по величине.
Ненормированное расширение прежнего генератора давало ошибку 1.44·10⁻⁷
и у исходного решателя, совпавшего с новым точно. Это дефект постановки
нового линейного контроля, а не изменение физического допуска; допуск
известного решения 10⁻¹² и все физические пороги сохранены.

```sh
node tests/cloth-implicit-motion.test.mjs
node tests/cloth-implicit-invariants.test.mjs
```

Известные движения, односторонняя кромка, восстановление после отказа,
поворот, зеркало, перенос и общий центр массы проходят.

## Изолированный контроль WASM

`tests/probes/cloth-linear-wasm.c` переносит ту же последовательность
вычитаний, делений и квадратного корня; запрещены слияние операций и
переассоциация. Оболочка создаёт отдельную память для каждого разложения,
сохраняет его для повторных правых частей. К `ImplicitEnergyMotion` и лодке
этот вариант не подключён. Это вычислительный опыт, не второй закон ткани.

```sh
PATH=/opt/homebrew/opt/llvm/bin:/opt/homebrew/opt/lld/bin:$PATH /opt/homebrew/opt/llvm/bin/clang --target=wasm32 -O3 -ffp-contract=off -fno-fast-math -nostdlib -Wl,--no-entry -Wl,--export-dynamic -Wl,--export=__heap_base -Wl,--initial-memory=131072 -o out/acceptance/cloth-linear-probe-v2.wasm tests/probes/cloth-linear-wasm.c
node tests/cloth-linear-wasm-probe.mjs --baseline=d3d25d9 --wasm=out/acceptance/cloth-linear-probe-v2.wasm --out=out/acceptance/implicit-linear-wasm-warm-clean.json
```

Положительная синтетическая матрица n=4000, полоса 305, 80 правых частей;
сначала малые контроли, затем первый большой случай и пять повторов.
Загрузка и компиляция WASM не входят в замер. Первое изучение на рабочей
версии инструмента дало медианы: исходный JS 341.54 мс, ускоренный JS
216.27 мс, WASM 157.96 мс. Выигрыш WASM против ускоренного JS около 1.37 раза;
эти числа не переводятся в ускорение всего паруса.

Повтор на чистом `63fef2b` подтвердил точное совпадение всех ответов:
371.47/243.40/175.40 мс для тех же трёх вариантов. Отношение ускоренного JS
к WASM 1.39; изменение абсолютных времён между запусками показывает,
почему одиночный замер не является постоянной характеристикой устройства.
`implicit-linear-wasm-warm-clean.json` имеет `dirty:false`, SHA256
`b1ff16fd548fefc9179dde5afd78047dc27eff3d4249c20683a02ed30d1d44c9`.

Ответы всех случаев совпали точно; отдельно проверены пустая/диагональная
матрица, полосы 3/161, полоса шире матрицы, повторные правые части и отказ
нулевого/отрицательного/нечислового/бесконечного диагонального элемента.
Запись сохраняет коммит исходного JS, отпечатки кода и бинарного модуля,
первый большой случай отдельно от прогретых. Первичный опыт нового модуля
также показал более дорогой первый запуск; возможные затраты загрузки,
создания памяти и множества малых матриц должны измеряться на полном уравнении.

## Быстрые подходы и выбранное совместное решение

Первичные источники сверены 2026-10-02:

- [Baraff, Witkin: Large Steps in Cloth Simulation](https://www.cs.cmu.edu/~baraff/papers/sig98.pdf):
  неявная ткань использует разреженную систему и итерационное решение с
  ограничениями. Прямое ленточное разложение теряет преимущество локальных связей.
- [Projective Dynamics](https://www.projectivedynamics.org/projectivedynamics.pdf):
  специальная форма энергии допускает постоянную общую матрицу и предварительное
  разложение. Нынешняя энергия SV20 этой формы не имеет; подмена закона ради
  предварительного разложения в данном ускорении не выполнялась.
- [SuiteSparse LDL](https://github.com/DrTimothyAldenDavis/SuiteSparse/blob/dev/LDL/README.txt):
  разреженное симметричное разложение разделяет анализ структуры и численные
  коэффициенты. Реализация проекта самостоятельная; код пакета не копировался.
- [Спецификация SIMD WASM](https://github.com/WebAssembly/spec/blob/main/proposals/simd/SIMD.md)
  имеет `f64x2`, позволяющий сохранить двойную точность. У
  [WGSL](https://www.w3.org/TR/WGSL/#floating-point-types) конкретные вещественные
  типы — f32/f16. Перенос нынешних строгих допусков на GPU требует отдельного
  исследования точности; для этого этапа выбран WASM на CPU.

Явные `--linear-backend=sparse-js|sparse-wasm` сохраняют прежнее исключение
планки и отдельные ответы всех действующих кромок. Области сетки исключаются
перед разделяющей полосой; структура разреженного фактора строится один раз.
Пакет независимых правых частей использует `f64x2`, без слияния операций или
переассоциации. Это не обеспечивает выигрыша само по себе: опыт +/21×17 на
рабочем дереве от `3e9e5c9` дал 16.26 с для sparse-js и 13.18 с для
sparse-wasm, против 12.82 с для band-js. Записи
`implicit-sparse-js-dev-plus.json`, `implicit-sparse-wasm-dev-plus.json`
сохраняют условия и отпечатки. Варианты остаются отрицательными контролями.

`--linear-backend=kkt-wasm` решает направление ткани и реакций совместно:
`[H G; Gᵀ 0][dx;mu]=[-grad;-C]`. H — прежняя матрица Гаусса–Ньютона,
G — те же градиенты кромок. Ограничение исключается после всех своих
координат; разложение L D Lᵀ проверяет ожидаемый знак каждого диагонального
элемента. Свободная связь имеет независимый единичный блок и нулевой ответ,
без штрафной жёсткости или ослабления ограничения. Отдельные большие
решения реакций больше не требуются. Последние принятые силы кромок
дают начальное приближение следующего шага; отказ не сохраняет новую историю.
Остановка, материал, шаг, ограничения и проверка настоящего градиента прежние.

Первый совместный вариант на +/21×17 занял 9.86 с. Профиль показал дорогое
повторное сопоставление координат с местами коэффициентов. Однократная
схема сборки уменьшила +/11×9,21×17 до 0.98/5.36 с. На +/41×33
`implicit-kkt-assembly-dev41.json` опыт занял 92.98 с против 521.82 с
контроля: 5.61 раза. Максимальное отличие сохранённых форм
3.842·10⁻¹⁴ м, энергетических полей 2.878·10⁻¹³ Дж. Ошибка сил на всех
шагах ≤10⁻⁶ Н, длины ≤10⁻⁹ м; число внешних итераций осталось 1651.
Профиль этого опыта: 59.43% выборок в разложении, 1.72% в подстановке.
Это рабочие версии от `3e9e5c9`, не чистый повтор и не приёмка FPS.

Измеритель `cloth-solver-comparison.mjs` отдельно проверяет неизменность входа,
пакета, кроя, параметров, допусков и происхождение исходников по Git.
Пределы воспроизведения сохранённых форм 10⁻⁸ м и энергии/работы 10⁻⁷ Дж
назначены до чистой серии; это контроль округления после замены алгоритма,
не изменение физических допусков и не G2. Независимая проверка измерителя
использует известный сдвиг 3–4–5 и известное изменение работы.

## Воспроизведение ускоренного опыта

Следующая версия хранит численные столбцы фактора рядом для повторных
обновлений, а соседние две координаты обновляет через `f64x2`.
Каждая координата получает ту же последовательность операций.
Известные положительные и совместные матрицы проверяют результат,
включая нечётные размеры и перестановки. На +/11×9,21×17 рабочей версии
от `fd34e14` время 0.92/5.43 с: дополнительный выигрыш здесь не доказан.
Проверка отказа после уже принятого шага сохраняет также историю множителей.
Чистая серия проверяет совместный вариант с этим ядром на всех трёх сетках.

```sh
make cloth-solver
node tests/cloth-sparse-solve.test.mjs --wasm=out/acceptance/cloth-sparse.wasm
node tests/cloth-implicit-motion.test.mjs --linear-backend=kkt-wasm --wasm=out/acceptance/cloth-sparse.wasm
node tests/cloth-implicit-invariants.test.mjs --linear-backend=kkt-wasm --wasm=out/acceptance/cloth-sparse.wasm
node tests/cloth-frozen-aero-grid.mjs --tack=1 --sheet=9 --iter=80 --fixed-load --grids=11x9,21x17 --mechanics --rigid-board --energy-material --implicit-motion --linear-backend=kkt-wasm --linear-wasm=out/acceptance/cloth-sparse.wasm --hold-cut-clew --cut-nesting --shared-input --continuous-cut --joined-cut-profile --seconds=1 --out=out/acceptance/implicit-kkt-clean-small-plus.json
```

Для другого направления используйте `--tack=-1` и новый файл. Для полной
сетки — `--grids=41x33`, также отдельный файл. Модуль и исходники защищены
от изменения во время опыта, SHA256 модуля записывается отдельно.
Сборка не меняет пакет аэродинамических сил. Для сравнения используйте
