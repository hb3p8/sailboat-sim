# Акватория и берег

## Данные и сборка

Реальная акватория собирается отдельно, чтобы основная сборка могла работать
без сети. Берег берётся из OpenStreetMap, рельеф — Copernicus DEM; скачанное
кэшируется в `data/terrain/`. Дно не промерено: глубина строится приближённо.
Течение, тень и изменение направления ветра также имеют оценочные параметры.

| Код/файл | Назначение |
|---|---|
| `src/sv20/terrain.py`, `scripts/build_terrain.py` | Исходные берег и рельеф |
| `scripts/build_terrain_pack.py` | Поля для быстрых физических запросов |
| `scripts/build_terrain_glb.py` | Графический ассет |
| `sim/terrain.js` | Доступ к полям, разгон, глубина, течение и укрытие |
| `viewer/terrain*` | Просмотр полей и редактирование разметки |
| `data/marks.json` | Стартовые точки, буи и фарватер |

```sh
make terrain terrain-pack terrain-glb
make sim
```

## Контракты

Физические поля используют мировые X=восток, Y=север. Сцена переводит их
через общий контракт; не меняйте карту отдельно от модели.
Пакет акватории необязателен. Нулевые дополнительные воздействия должны
сохранять поведение режима без акватории.

Геометрия укрытия отделена от подбираемых параметров тени. Ограничение разгона
поперёк узкой реки может сохранять дефицит ветра даже у фарватера; не требуйте
восстановления до открытого моря там, где для этого нет расстояния.
Положение лодки ограничивается урезом; одной корректировки скорости
недостаточно для запрета медленного проникновения в изогнутый берег.

Уровень точности разный: берег и рельеф имеют источник, дно и скорость течения
не являются промерами. Не используйте игровую глубину как навигационные данные.

## Разметка и сервер

Просмотрщик получает поля по серверу и сохраняет `data/marks.json` через
`/api/marks`. На `--lan` изменение разметки отключено. Производные профили
и снимки сохраняются отдельно в `out/`; это не изменение исходной карты.
Подробности запуска — в [симуляции](../guides/simulation.md).

## Восстановление вида берега по видео

`scripts/video_shots.py`, `sfm.sh`, `video_masks.py`, `splat_orient.py` и
`splat_render.py` образуют исследовательский конвейер. Первый пролёт дал
реконструкцию с ограниченным параллаксом; её полезность с уровня воды
не доказана. Съёмка сверху не гарантирует качество силуэта с лодки.
Источник и условия использования — [реестр видео](../../data/video/SOURCES.md).
Включение чужих производных материалов требует проверки лицензии/разрешения.

Команды и результаты конвейера сохраняются в исследовательском разделе;
этот путь не блокирует первые учебные упражнения.

## Проверки

`tests/terrain.test.mjs` проверяет выборку, интерполяцию, берег и вырождение
без пакета. При изменении визуализации проверяйте карту и вид с воды;
при изменении физических полей — связанные силы и их отсутствие при нулевых
настройках. Не переписывайте кэш или исходную разметку ради удобного теста.
